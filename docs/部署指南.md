# 誉友科技 · 部署指南

> 适用对象：维护/上架人员。站点为纯静态站，无需编译，支持本地双击运行与 GitHub Pages 两种方式。

---

## 一、本地离线运行

1. 将整个项目文件夹（含 `index.html`、`pages/`、`assets/`、`shared/`）复制到任意目录；
2. 双击根目录 `启动.bat`（内含 `%~dp0` 自动定位目录 + `chcp 65001` 防中文路径乱码），会自动启动本地服务并打开预览器；
3. 或手动方式：在项目根目录执行
   - Windows：`python -m http.server 8905 --directory "项目绝对路径"`
   - 然后浏览器访问 `http://localhost:8905/`（根链接自动跳转到手机首页 `pages/418843.html`）；
4. 全站资源均为本地引用，**断网可用**。

> 注意：建议用无痕窗口或 Ctrl+F5 强制刷新访问，避免浏览器缓存旧版本。

## 二、部署到 GitHub Pages（当前线上环境）

线上地址：`https://yuyoukji.github.io/yuyoo-tech/`（仓库 `yuyoukji/yuyoo-tech`，分支 `main`）。

### 方式 A：命令行推送（推荐，仓库相关命令）

```bash
cd 项目路径
git add -A
git commit -m "feat: 上线优化"
git push origin main
```

仓库自身已在 GitHub 设置中开启 Pages（Source = main，根目录），推送后约 1-3 分钟构建完成。

### 方式 B：无 Git 本地环境的脚本方式（API 推送）

若本机无法直连 `github.com:443`/`github.io`（国内网络常见被重置），可使用仅需 `api.github.com:443`（可达）的 Git Data API 推送流程：

1. 准备 `gh` CLI 并已认证；
2. 将全部变更文件 base64 编码后 `POST /repos/yuyoukji/yuyoo-tech/git/blobs`；
3. 用得到的 blob sha 组装 tree：`POST /repos/{owner}/{repo}/git/trees`（base_tree 指向当前 HEAD）；
4. `POST /repos/{owner}/{repo}/git/commits` 生成提交；
5. `PATCH /repos/{owner}/{repo}/git/refs/heads/main`，`{"sha":"<commit-sha>","force":true}` 完成更新；
6. 校验：`GET /repos/yuyoukji/yuyoo-tech/pages` 确认 `status=built`。

> 注意事项：API 偶发瞬时 404 属正常，间隔 2-3 秒重试；`force` 参数必须传布尔类型；新开的 PowerShell 进程需执行 `$env:Path="C:\Program Files\Git\cmd;C:\Program Files\GitHub CLI;$env:Path"` 才能找到 git/gh。

## 三、部署到阿里云 ECS（生产环境）

目标实例：`i-bp1bpchjyq95bwgh8752`。站点为纯静态站，用 Nginx 托管，无需编译。

### 3.1 前期准备（阿里云控制台）

1. **安全组**：实例安全组入方向放行 `80`（HTTP）与 `443`（HTTPS），不对公网开放 `22` 之外的端口；
2. **域名备案**：将已备案域名解析（A 记录）到实例公网 IP；
3. **证书**：申请域名正式 SSL 证书（阿里云 SSL 证书/免费证书即可），备用。

### 3.2 上传站点（本机 Windows 执行）

在项目根目录 `deploy/` 下执行：

```powershell
powershell -ExecutionPolicy Bypass -File deploy\deploy-h5.ps1 -Server <ECS公网IP> -User root -Domain <你的备案域名>
```

脚本会 `scp` 上传 `index.html`、`pages/`、`assets/`、`shared/`、`deploy/` 至 `/var/www/yuyoo-tech/`，并在指定域名时自动在 ECS 上执行安装脚本。

### 3.3 ECS 上安装（install-server.sh 自动完成）

- 安装 `nginx` + `openssl`；
- 生成自签名占位证书（生产环境请将 `/etc/nginx/ssl/<域名>.pem/.key` 替换为正式证书后 `nginx -s reload`）；
- 用 `nginx-site.conf` 模板生成站点配置（HTTP→HTTPS 跳转、30 天静态资源缓存、HTML 不强缓存、安全响应头、gzip）；
- `nginx -t` 校验后启动服务。

### 3.4 部署后验证

| 验证项 | 方法 |
| ---- | ---- |
| 站点可访问 | 浏览器访问 `https://<域名>/`，应自动跳到产品首页 |
| 强制刷新生效 | Ctrl+F5 后确认 Logo/新内容为最新版 |
| 日志无异常 | `tail -f /var/log/nginx/yuyoo-tech.error.log` |

### 3.5 后续更新发布

重复 3.2 上传即可（HTML 不强缓存，上传后刷新即生效）。
