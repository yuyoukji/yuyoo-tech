## 二、日常维护操作

### 1. 修改产品数据（最常用）
1. 打开 `shared/data.js`；
2. 修改产品名称/标语/描述/图片/详情参数（产品亮点、技术栈、行业实践）；
3. 产品分类 id 必须存在于 `CATEGORIES`；新增产品记得补 `DETAILS` 详情；
4. 图片文件名需与 `assets/img/products/` 中实际文件**完全一致**；
5. 保存后，首页/分类/搜索/详情/收藏页自动联动生效（它们都读同一数据源）。

### 2. 新增/替换图片
1. 将图片保存到 `C:\Users\Administrator\Desktop\誉友科技\assets\img\products\`，命名按上述清单；
2. 尽量使用高清（≥1200px 宽、色偏深）图片，避免作背景时拉伸模糊/文字难读；
3. 新背景图需叠加深色遮罩以保证文字可读性。

### 3. 修改客服电话 / 联系方式
- 全站电话统一在以下位置修改为 `199-1703-3375`：
  - `pages/418800.html`（联系客服页 + tel: 链接）
  - `pages/418799.html`（关于我们）
  - `pages/418828.html`（隐私政策）
  - `pages/418851.html`（消息详情）
  - `pages/420306.html`（公司介绍）
- 禁止在任何客户界面添加微信/二维码联系方式。

### 4. 修改品牌主色/主题
- 品牌色、间距、圆角变量集中在 `assets/css/app.css` 的 `:root`。

### 5. 新增页面
1. 在 `pages/` 下复制一个同风格页面并改名（文件名建议沿用 6 位数字 id 风格）；
2. `<head>` 中必须引入：
   ```html
   <link rel="stylesheet" href="../assets/css/app.css">
   <script src="../assets/js/ui.js"></script>
   ```
3. （tabBar 页）额外引入 `<script src="../assets/js/tabbar.js">`，并把页面 id 加入该文件的 `TABS` 数组文件名匹配列表；
4. 在 `index.html` 的左侧菜单列表补充菜单项。

## 三、常见问题排查

| 现象 | 原因 | 处理 |
| ---- | ---- | ---- |
| 页面显示旧版内容 | 浏览器缓存 | Ctrl+F5 强刷 / 无痕窗口 / 清站点缓存 |
| 产品图不显示、出现 💻 占位图 | 图片缺失或文件名与数据不一致 | 核对 `shared/data.js` 的 image 与 `assets/img/products/` 实际文件 |
| 背景图拉伸模糊 | 原图分辨率低 | 换高清图并保持 `cover` + `center` 样式 |
| 非微信浏览器访问线上显示白屏 | 国内直连 github.io 资源加载失败 | 改用本地运行，或更换 CDN/自有域名 |
| 设置项不生效 | 键名未用 `yuyoo_setting_` 前缀 | 统一前缀，避免键冲突 |

## 四、变更规范（硬性要求）

1. **不改动**首页 banner 轮播（`banner-*.jpg` 及轮播实现），保持原样；
2. 后台图标与数据「密集、深色调」优先，新背景必须叠加遮罩；
3. 不引入任何远程资源（CSS/字体/JS/图片全部本地化，保证离线）；
4. 微信小程序工程涉及同源数据时，只改 `shared/data.js`，双端自动一致；
5. 发布前过一遍「部署指南.md」的上线清单核对表。
