- 品牌统一为「誉友科技」，禁止出现「久易」品牌元素；
- 客户服务热线统一为 `199-1703-3375`（呼出号码 `19917033375`）；
- 所有客户界面（页面、文档、素材）不展示任何微信客服联系方式；
- 主视觉品牌橙 `#ff7a18`，配合品牌蓝 `#1a7fd4` 与灰阶体系。

## 三、核心业务链路

1. **搜索 → 结果 → 详情**：首页/搜索页输入关键词 → 结果页匹配产品（名称/标语/描述/分类）→ 进入详情页按 id 联动展示对应产品参数；
2. **分类 → 详情 → 收藏**：分类页/首页选分类 → 产品网格 → 详情页收藏 → 个人中心「我的收藏」管理；
3. **登录 → 资料**：登录页（授权/验证码）→ 个人中心 → 我的资料（手机号脱敏）；
4. **反馈 → 记录**：意见反馈提交 → 反馈记录列表实时可见；
5. **客服触达**：各页联系客服 → 拨打电话（`tel:`）/ 在线反馈。

## 四、数据层（单一数据源）

- `shared/data.js`：双端（H5 / 微信小程序）共用的产品数据源，集中管理：
  - 6 大类分类（软件开发/APP开发/小程序/云服务/数据服务/运维支持）；
  - 5 款产品（誉友ERP / 誉友CRM / 微信小程序开发 / 移动APP开发 / 云服务器部署），含技术参数（技术栈/开发框架/部署方式等，无农业字段）；
  - 3 张首页 banner；
  - 每款产品的详情扩展（产品亮点 / 技术栈 / 行业实践）。
- `assets/js/products.js`：H5 侧适配层，暴露 `YUYOO_PRODUCTS` / `YUYOO_CATEGORIES` / `YUYOO_BANNERS` / `YUYOO_getProductById` 等全局变量，并内置图片加载失败时的 SVG 占位兜底函数 `yuyooProductImage()`。

## 六、安全与合规

- 搜索结果页对 URL 参数反射做 **HTML 转义**（`esc()`），杜绝反射型 XSS；
- 商品/详情数据仅含科技产品技术参数，不含农药登记证号、毒性、有效成分等农业字段；
- 全站无远程资源依赖、无第三方追踪脚本，隐私政策/注册协议双文档齐备。
